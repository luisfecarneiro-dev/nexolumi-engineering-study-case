# Contributing

This repository is an author-maintained engineering case study, not an open-source implementation of NexoLumi CRM.

Corrections to typos or documentation can be proposed through issues or pull requests once the owner enables and reviews them. Please do not submit secrets, customer information, production screenshots, private logs or code from private repositories.

If referencing test counts or release status, state the **date**, **source type** and **verification limitations**. Do not change NO-GO to GO unless new owner-approved evidence exists.
