# Public assets

This case study intentionally ships without screenshots or customer images.

Before adding media:

1. Capture a demo workspace using synthetic data, never real customer conversations.
2. Redact names, phone numbers, message bodies, avatars, IDs and session identifiers.
3. Avoid exposing administrator URLs, internal service hosts and observability dashboards.
4. Confirm branding/image rights.
5. Revalidate all files for embedded metadata and accidental tokens before publishing.

Recommended eventual illustrations: sanitized product overview, a synthetic kanban workflow, and a conceptual architecture diagram. None are required to understand this documentation.
