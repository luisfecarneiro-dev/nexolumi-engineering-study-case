# Security policy for this case-study repository

This repository contains documentation only. It is **not** the NexoLumi production codebase, and no application service should be run from it.

If you notice sensitive material accidentally disclosed here, do not reproduce it in a public issue or discussion. Notify the author through a private channel linked from [07Dev](https://07devpagerp.com.br). Do not share customer personal data, credentials or reproduction details publicly.

The publicly described architecture should not be treated as a statement of verified security certification. Production security reports, credentials and internal operational details are intentionally excluded.
